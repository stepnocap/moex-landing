# MOEX — Регистрация внебиржевых договоров (лендинг-концепт)

Одностраничный лендинг сервиса: загрузка скана договора → распознавание полей →
предзаполненная форма регистрации с подсветкой уверенности и проверкой по правилам биржи.
Концепт для хакатона Московской биржи 2025.

## Посмотреть онлайн

GitHub Pages: **https://stepnocap.github.io/moex-landing/** (появится после включения Pages).

## Запуск локально

Нужен Node.js.

```bash
npm install          # один раз — ставит puppeteer (для скриншотов, для запуска не обязателен)
node serve.mjs       # сервер на http://localhost:3000
```

Откройте http://localhost:3000 и нажмите «Показать на примере» в секции «Демо».

> Живое демо подгружает `assets/mock-response.json` через `fetch`, поэтому открывать нужно
> через сервер (`node serve.mjs`), а не двойным кликом по `index.html`.

## Структура

```
index.html              # вёрстка + inline-стили
assets/demo.js          # логика демо: распознавание → форма → валидация → отправка
assets/mock-response.json  # пример ответа по API-контракту (поля + ошибки валидации)
brand_assets/moex-logo.svg # официальный логотип MOEX
serve.mjs               # локальный статический сервер
screenshot.mjs          # Puppeteer-скриншоты (dev-утилита)
```
